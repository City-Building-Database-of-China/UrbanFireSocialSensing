# Data and figure usage

The MIT license in this repository applies only to software code. It does not grant a license to the datasets, figure source tables, figures, manuscript material or third-party inputs.

A separate data reuse license has not been specified. Availability for inspection does not establish an unrestricted right to redistribute or reuse these materials. Obtain the relevant rights-holder permission where required, respect applicable provider terms and cite the study and repository when using permitted material. No Creative Commons license is asserted by this package.

The public files comprise processed numerical evidence, anonymous demonstration data and aggregate validation results. Raw social-media narratives, identifying record links, original building identifiers, addresses, coordinates, location crosswalks, detailed spatial layers and the complete internal modelling matrices are outside the public scope. Public anonymous identifiers have no released mapping to original records.

Third-party building, demographic, socioeconomic and geographic sources retain their own terms. Provider information and scientific field definitions are available in the supplementary tables and metadata. Consult the figure-specific notes for the scope of each source table.
